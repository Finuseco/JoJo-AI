Expliquer, recevoir, collaborer

Votre demande devient une conversation.

Gardez vos échanges et vos fichiers dans le contexte du projet, puis vérifiez les propositions de l’assistant avant de les appliquer.

Dictez votre demande

Utilisez le micro du chat pour transcrire votre voix en texte. Relisez la transcription, corrigez-la si nécessaire, puis envoyez-la à l’assistant. Une clé OpenAI configurée et l’autorisation du micro sont nécessaires.

Joignez vos références

Envoyez des images, un PDF ou des documents texte avec votre message. Recevez la réponse dans le chat et examinez les fichiers proposés dans le panneau des modifications.

Partagez le projet

Depuis vos projets, invitez un développeur CashPay par e-mail. Après acceptation, il rejoint le même projet. Pour publier votre code, connectez GitHub et envoyez un commit depuis le panneau GitHub.

De votre besoin à votre projet

Un cahier des charges clair fait la différence.

Présentez ce que vous voulez construire, pour qui et dans quel ordre. Copiez votre cahier des charges dans le chat du projet et ajoutez des captures utiles.

Concevoir, vérifier et préparer la suite.

Le studio rassemble les outils de votre projet. L’exécution, l’hébergement et l’émulateur Android sont disponibles lorsque les services correspondants sont activés.

Code et dépendances

Données et collaboration

Visuels et aperçu

Comment récupérer ou publier votre travail ?

Testez d’abord votre projet. Téléchargez vos sources en ZIP ou synchronisez-les avec GitHub. Pour un site statique, utilisez la publication du studio si l’hébergement est activé, puis configurez votre domaine. Une application Android nécessite aussi sa compilation, ses tests et sa signature avant distribution.

Continuer dans le studio

Travailler où vous voulez

En local, avec GitHub, ou directement dans le studio.

Importez ce que vous avez déjà, travaillez avec vos propres outils ou codez dans le studio. Votre code reste le vôtre.

Importer vos projets

Importez une archive ZIP ou un dépôt GitHub : vos fichiers arrivent dans le studio, prêts à être modifiés avec l’assistant.

Travailler en local

Exportez votre projet en ZIP, ouvrez-le dans votre éditeur habituel, puis réimportez vos fichiers pour continuer avec l’assistant.

Coder directement

Modifiez vos fichiers dans l’éditeur du studio, lancez les commandes npm prises en charge dans le terminal du projet et consultez l’aperçu.

Synchroniser avec GitHub

Connectez votre compte GitHub, choisissez un dépôt et une branche, récupérez les changements distants, puis publiez vos modifications dans un commit. Aucun push forcé.

Suivre l’historique

Retrouvez les derniers commits du dépôt lié depuis le studio, pour savoir où en est votre branche.

Supprimer un projet

Vous pouvez supprimer un projet dont vous n’avez plus besoin depuis le studio. Exportez-le d’abord en ZIP si vous souhaitez en garder une copie.

Avant de commencer

Quelques réponses.

Puis-je reprendre une application déjà créée ?

Oui. Importez vos fichiers en ZIP ou connectez votre dépôt GitHub depuis le studio. Vous pouvez ensuite travailler dans vos sources.

Les modifications sont-elles appliquées sans moi ?

Le studio présente les propositions pour validation. Vous pouvez les comparer et les accepter avant de modifier vos fichiers.

Est-ce que je garde accès à mon code ?

Oui. Vous pouvez lire et modifier les fichiers dans l’éditeur, exporter une archive ZIP et utiliser les fonctions GitHub après connexion.

Quel compte utiliser pour me connecter ?

Utilisez votre compte développeur CashPay. Le bouton d’accès au studio vous accompagne pour retrouver votre session et vos projets.

Puis-je travailler depuis mon téléphone ?

Oui. Le tableau de bord et le studio ont une navigation mobile adaptée, avec les projets, le chat, les fichiers et l’aperçu.
